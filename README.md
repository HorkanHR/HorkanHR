# Hi, I'm Helen 

I'm PhD-trained in **genomics data science / biochemistry**. I consider myself a **'full-stack biologist'**: I work from the bench (sample prep, assay design, library construction) through to the analysis (pipelines, statistics, visualization). I like owning the whole path from tube to figure, because the best computational choices are informed by what happened in the wet lab, and the best wet-lab choices are informed by what the data later show.

## What I care about

Science should be open and accessible to everyone. For me that means:

- **Open code.** Documented, reproducible analysis that others can run, read and change.
- **Open wet-lab methods.** Protocols you can reproduce without a proprietary kit.
- **No paywalls.** Free tools for people who can't, or don't want to, buy software or kits.
- **Approachable tools.** Interfaces that people without a coding background can use, and learn from as they go.

If a method only works for those who can afford the tools, it isn't finished.

## What I build and share

- Reproducible workflows for genomics data analysis
- Free, open-source tools with friendly interfaces that teach as you explore
- Low-cost, open alternatives to commercial software and kits, with the protocols to match
